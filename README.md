# La Bebesota · Mixes Mexas — propuesta de diseño v1

Bar de barrio en La Paz, Puebla. Concepto: neón Y2K con **modo día / noche** (automático por la hora de Puebla + interruptor).

Secciones: buffet $149 con cuenta regresiva, la semana en bolas de billar, cartelera automática, photobooth, reserva con vista previa del chat, grupos, ubicación y FAQ.

Por confirmar: WhatsApp, dirección (19 Sur 1101 vs 19 Sur 101 altos), contenido de paquetes.

Ver en local: `python3 -m http.server 3034`.
